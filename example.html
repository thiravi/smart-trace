🎯 SmartTrace Widget Demo

This page demonstrates how to embed the SmartTrace feedback widget into any website. The widget automatically records user sessions and allows users to submit feedback with session replay data.

🎮 Try the Widget

Click the 💬 button in the bottom-right corner to submit feedback. Your session is being recorded automatically!

📝 Basic Integration

<!-- Add this script tag to your website -->
<script src="https://your-cdn.com/smart-trace.umd.cjs"></script>
<script>
  // Auto-initialize with default settings
  initSmartTrace();
</script>

⚙️ Custom Configuration

<script>
  initSmartTrace({
    position: 'bottom-left',
    showRecordingControl: true,
    onFeedback: (data) => {
      console.log('Feedback:', data);
      // Send to your API
    }
  });
</script>

🔧 Configuration Options

  • position: 'bottom-right' | 'bottom-left' | 'top-right' | 'top-left'
  • showRecordingControl: Show manual start/stop recording buttons
  • autoStart: Automatically start recording on page load (default: true)
  • onFeedback: Callback function to handle feedback submissions
  • apiKey: Your API key for authentication
  • apiEndpoint: Custom endpoint for feedback submission

📊 What Gets Recorded

  • 🖱️ Mouse movements and clicks
  • ⌨️ Keyboard interactions (non-sensitive)
  • 📱 Viewport changes and scrolling
  • 🔄 DOM mutations and updates
  • 💻 System information (browser, OS, performance)
  • 🌐 Network information (connection type, speed)
